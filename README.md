# Cleartrip, planned together: presentation

An AI trip planner for groups and weekend escapes, built for the Razorpay Design assignment.

- **Documentation** (`docs.html`): the project story as 18 visual sections, including four annotated user flows (flowchart plus annotated screens): the brief, nine conversations, patterns to possibilities, directions weighed, the user flow, edge cases, how AI is used, decisions and next steps. Exported from the Figma board.
- **Annotated prototype** (`prototype.html`): the live working app, step by step, with numbered notes on what each screen does and why. It embeds the live prototype from https://rushabhm-blip.github.io/Cleartrip_ai_agent/ using its `?jump=` states.

Open `index.html` to start. Everything is static HTML, CSS and images, so it works on GitHub Pages (Settings, Pages, deploy from `main`, root).

A concept for Cleartrip, not an official release. Prices, places and AI replies are samples.
